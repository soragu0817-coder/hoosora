# 칼럼 질문 목록

환자가 AI나 검색창에 실제로 물어볼 법한 구체적인 질문 목록입니다.
칼럼은 여기서 아직 쓰지 않은 질문(`- [ ]`)을 골라 씁니다. 발행하면 `- [x] 질문 (발행일, 칼럼 주소)`로 바꿉니다.
